# 前端共用规范

本能力供涉及 Web 前端实现和审查的任务使用。先读取目标项目约定，确定受影响的前端应用和技术栈，再按改动加载下面的规范。项目适配器给出本项目的具体覆盖、目录例外、组件、浏览器范围和验证入口。

- 页面、组件、路由入口、公开导出、样式文件归属或跨模块引用有变化时，读取[前端目录结构](frontend/structure.md)，核对所有者、入口和实际消费者。
- 涉及布局、样式、交互呈现、视觉或控件时，读取[Web 前端设计规范](frontend/design.md)，再按实际项目设计和宿主约束验证。
- 同时命中代码审查时，由同一个 reviewer 核对共用规范、项目约定及验证证据。按改动实际影响覆盖视觉、尺寸、交互或使用者回归。
